Grocery Store, refreshed

Admin screens that are designed but not built yet. Calmer type: 13px text, 20px page titles, medium and semibold weights only. Thin borders with light shadows, and smaller 30–34px controls.

Orders board

Filters sit in one row with search first. Each status is a light grey lane, and empty lanes show one short line. Cards are compact: the order number and time, the address, the slot, then items and total, then the actions.

Products table

The table fills the screen down to the bottom edge and scrolls inside, with the column names fixed at the top. Underneath: the count shown, rows per page and page buttons. Packs of one product line up row by row. Stock problems are small coloured pills.
