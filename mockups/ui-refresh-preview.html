Grocery Store, refreshed

Admin screens that are designed but not built yet. Screens already in the app have been removed from this page.

Add product

Cancel and Add product move to the top, next to the title, so they are always in reach. The form sits on the left in two cards; a narrow column on the right holds the photo (now possible while adding), the Show in the shop switch, and a live preview of the product card exactly as customers will see it. Each pack size shows its discount as soon as MRP and price are filled.

Edit product

The same layout. The title shows whether the product is in the shop. Stock is a read-only number with an Adjust link to the Stock page, since stock changes are logged on the Stock page. Each pack size has its own show switch and a remove button; the preview shows the first pack with its discount badge.

Bulk upload

Three step cards across the page instead of one narrow box. Step 1 lists every column in the template (dashed ones are optional). Step 2 gives the four rules that cause most mistakes. Step 3 is a drop area; once a file is chosen it shows the file name and row count with one Upload button. Results come back as a green Saved line, or a red list of problem rows with the fix written out.
