Kitchen Pantry, refreshed

The same green and yellow, the same screens and the same flow. What changes is depth, shape and type: soft shadows instead of hairline borders, rounder corners, a curved header and a floating tab bar. Prices and headings get a bolder display font.

Home: now vs refreshed

The search bar sits over the curved header edge. The delivery address becomes a tappable pill, and the category tiles get soft lighting, so the tiles look like things you can tap.

Category list and product page

The discount moves onto the photo, so the price line stays clean. ADD is a tinted button that turns solid once something is in the cart. The cart bar shows what's inside. Pack sizes on the product page show their own price.

Loaders

Right now both the app start and every page show the word "Loading…" on a blank screen. Instead, the app opens on a branded green screen. Pages show grey placeholder cards in the shape of the content that's coming, so nothing jumps when it arrives. Buttons that are saving get a small spinner.

Admin dashboard

The sidebar gets a yellow icon on the active page and a count badge on Orders. Each stat tile has an icon and a status dot, and the tables lose most of their lines. On a phone, scroll this frame sideways.

What changes in the code

Most of this is in styles.css. A few components need small markup changes. No new packages, no logic changes.

Depth instead of lines

Card borders become two soft shadows tinted with the brand green. Corner radius goes from 12–16px up to 16–20px.

Display font

Plus Jakarta Sans for headings, prices and stat numbers. Noto Sans stays for everything else. It's one more Google Fonts weight set.

Curved header

Gradient green with a rounded bottom edge. The search box overlaps that edge, and the delivery line becomes a glass pill.

Floating tab bar

A frosted pill with a green-tint highlight behind the active icon. Same TabBar.jsx, one extra wrapper span.

Product cards

The discount badge moves onto the photo, ADD becomes a tinted button and the pack picker becomes a pill. Small changes in ProductCard.jsx.

Loaders

LoadingScreen in RouteGuards.jsx becomes the green start screen. LoadingOrError shows shimmer cards instead of the word "Loading…", so every page that uses it changes at once.

Feel

Buttons shrink slightly when pressed and colours change with 150ms transitions. Both turn off under reduced motion. Yellow focus rings stay as they are.
